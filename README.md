# Prompt Halo

Prompt Halo 是一个面向游戏原画工作流的提示词常驻工具原型：把常用的补图、裁剪、转向、风格迁移和光影提示词整理成可搜索、可收藏、可组合的快捷库。

## 已实现

- 三栏提示词工作台：分类、提示词卡片、编辑器。
- 搜索、收藏、最近使用排序、新建、复制副本和常用后缀。
- 光标附近的 Halo 圆环，支持最近、分类、收藏和搜索。
- 程序启动后默认隐藏到系统托盘，不再常驻显示主界面或圆环。
- `Ctrl + Alt + Q` 全局呼出透明 Halo 窗口，圆环中心会对齐到鼠标附近。
- 默认操作是点击：点击分类 → 点击具体提示词 → 圆环立即关闭并开始注入。
- 圆环以不激活方式呼出；点选时菜单可以获得焦点，插入前会恢复已记录的原窗口与输入控件。点“搜索”会主动获取键盘焦点。`Esc` 或点击外部区域可取消。
- Electron 会在呼出前记录前台窗口和焦点控件；选择提示词后自动恢复焦点并发送粘贴事件，不需要用户再按 `Ctrl + V`。
- 浏览器版保留“演示模式”，内容写入页面内的演示输入框。
- 数据默认保存在当前设备的 `localStorage` 中。

## 运行

浏览器预览：

```powershell
npx serve .
```

桌面版：

```powershell
npm install
npm run desktop
```

先在目标文本框放置光标，再按 `Ctrl + Alt + Q`，点击具体提示词即可自动输入。主库窗口可以从托盘“显示提示词库”打开，主库“试用菜单”只向演示输入框输入。修改源码后须退出旧实例再启动；重复启动只唤醒现有进程。托盘显示本次加载的源码版本号。

## 故障诊断

托盘 → 打开输入诊断。也可在主库设置中查看运行版本和最近结果。
诊断文件保存在 Electron 用户数据目录的 `input-diagnostics.json`，只记录最近 60 个输入链路事件；不保存提示词正文、剪贴板内容、网页地址或聊天记录。

- `target-captured`：呼出时的窗口、焦点句柄和进程。
- `selected`：已收到提示词点选，记录长度。
- `input-result`：Windows 返回的阶段、错误码、发送数量与双方权限等级。
- `failed`：未完成操作的原因，同时显示托盘错误通知。

`input-dispatched` 只表示 Windows 接收了模拟按键，不表示任意目标程序已经修改文档。不能将剪贴板有内容或 `sent: 4` 作为自动输入成功的证明。

## 验证

- `npm run test:native`：独立 Electron 测试窗口，真实系统热键、鼠标点击、实际文本值、取消和重新呼出。
- `npm run test:chrome`：独立 Chrome 临时配置和本地 contenteditable；在已有文字中间插入，必须只发生一次粘贴且旁边输入框不变。
- `npm run test:chrome -- --search`：搜索获得焦点后自动输入。

测试短暂使用系统鼠标键盘，期间请勿操作；测试会校验目标身份，在前台变化或检测到人工输入时失败，不应删除这些保护来强行得到通过结果。

2026-09-14 用户已在两个浏览器、微信、QQ、Photoshop 文字输入和 Typora 中确认不同输入框位置均可准确写入。此结论来自用户现场验收，不代表覆盖所有软件或权限环境。

源码回退及验收标签见 `VERSIONING.md`。个人词库不随 GitHub 源码上传。
