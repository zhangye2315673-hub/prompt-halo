# QEA CueRing｜词环 0.2.0-beta.1

日期：2026-09-16。预发布测试版，Windows x64。

## 本版内容

- 深灰紫与亮绿的扁平圆环，中心新增、编辑、外圈控制。
- Q 品牌图标采用实底和缩小 10% 的图形，用于 EXE、窗口与托盘。
- 词库导入、导出、修改前备份、历史恢复、未保存修改确认。
- 托盘保留日常操作，移除开发诊断与构建信息。
- 常规安装版安装一次后直接运行；ZIP 版完整解压一次。
- 保持既有输入目标捕获、焦点恢复、单次粘贴和防过期保护。

## 验证边界

本机自动检查：输入契约、菜单生命周期、词库校验与备份、未保存关闭保护；包内 Electron 隐藏渲染器检查。具体执行结果以发布交付记录为准。

尚未完成：另一台无开发环境电脑、Windows 11 实机、企业脚本策略、各缩放比例及多屏的完整真实输入验收。不可标为全部电脑兼容。

## 试用验收清单

- 标准用户首次安装或完整解压后启动，桌面与开始菜单入口正确。
- 浏览器、聊天框、Photoshop 中实际输入一次，无重复且目标正确。
- Ctrl+Alt+Q 冲突有提示，托盘仍可使用。
- 保存词库后重启；导出、合并导入、历史恢复保持正文与顺序。
- 未保存编辑退出时，继续编辑与放弃修改行为正确。
- 100%/150%/200% 缩放、多屏边缘呼出不截断。
- 更新及卸载不删除个人词库。

## 已知限制

EXE 未签名。系统需要 Windows PowerShell 和 .NET/UIAutomation。暂无自动更新；更新前退出应用并先导出词库。文件图标可能受 Windows 图标缓存影响。项目开源许可尚未由作者选定，第三方声明随包保留。
